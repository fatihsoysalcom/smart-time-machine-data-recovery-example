# Smart Time Machine Data Recovery Example

This example demonstrates the core concept of a "Smart Time Machine" for data recovery and versioning, as described in the SARAH v1.0.9 article. It simulates a project file that undergoes modifications, with the ability to save snapshots of its state and restore to any previous version. This showcases how a system can provide robust data protection and rollback capabilities.

## Language

`python`

## How to Run

1. Save the code as `smart_time_machine.py`.
2. Run from your terminal: `python smart_time_machine.py`
3. Observe the creation of `my_project_data.txt` and `project_history` directory, and the restoration process.
